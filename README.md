# Клеомед — сайт стоматологической клиники

Статический сайт стоматологии «Клеомед» (Санкт-Петербург).

## Структура

| Путь | Что это |
|---|---|
| `site/` | **Актуальная версия сайта** — свёрстана вручную |
| `site/css/style.css` | Единственный файл стилей, с токенами палитры |
| `site/js/main.js` | Меню, модалка записи, лайтбокс, аккордеоны, reveal-анимации |
| `site/404.html` | Страница «не найдено» |
| `site/robots.txt`, `site/sitemap.xml` | Для поисковиков; домен в них записан в punycode |
| `site/img/` | Фотографии клиники, работы «до/после», лицензии |
| `site/fonts/` | TildaSans (woff2), 5 начертаний |
| `assets/`, `*.html` в корне | Исходная выгрузка старого сайта с Tilda — справочный материал |
| `server/` | Сервис приёма заявок: хранит их в РФ и заводит карточки в Битрикс24 — см. `server/README.md` |
| `serve.py` | Локальный сервер предпросмотра с отключённым кешем |

## Локальный запуск

```bash
python serve.py          # http://localhost:8080/site/
python serve.py 9000     # другой порт
```

В отличие от `python -m http.server`, этот сервер запрещает кеширование —
после замены картинки или правки CSS не нужно каждый раз жать Ctrl+F5.
Он же повторяет два правила боевого nginx: адреса без `.html` и своя
страница 404 — иначе локально нельзя проверить ровно то, что увидят люди.

Чтобы работала форма записи, рядом нужно поднять сервис заявок:

```bash
KLEOMED_DB=./leads.db python server/leads.py    # в соседнем окне
```

Без него форма честно скажет, что отправить не удалось.

## Палитра

У сайта две темы, переключатель в шапке, выбор хранится в `localStorage`.

* **Тёмная** (по умолчанию): почти чёрное поле `#05100D`, свет из одной
  точки за объектом, бирюзовый `#34C88A` для кнопок и акцентов.
* **Светлая**: салатовое поле `#D5E8C1` (герой — насыщенный `#BCD9A5`),
  поле светится к центру, зелёный уведён в глубину до `#1F8049` —
  салатовый на салатовом для текста не годится.

Тёплый акцент — только для акций, чтобы взгляд шёл на них.
Все пары «текст / фон» проверены на контраст не ниже 4.5:1. Единственное
исключение — белая половина заголовка героя в светлой теме: так собран
макет, держится она на кегле под 130px и мягкой тени.
